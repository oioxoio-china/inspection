# 泸州龙透关隧道工程检验批验收用表设计研究

## 项目概述

本项目针对泸州龙透关隧道工程，开展检验批验收用表设计研究工作。核心目标是将《公路工程质量检验评定标准》（JTG F80/1-2017）和《公路隧道施工技术规范》（JTG/T 3660-2020）两部权威规范进行系统整合，形成可用于指导实际施工验收的标准化表格工具。

## 研究成果

### 核心交付物

| 交付物 | 说明 |
|--------|------|
| 融合规范-检验批验收用表 | 20项分项工程检验批用表，融合双规范要求 |
| 质量控制标准表 | 38个JTG/T 3660-2020质控标准表 |
| 隧道工程分部分项检验批验收方案 | 完整的验收方案文档（Word/PDF） |

### 统计数据

- **分项工程**：20项
- **质量控制标准表**：38个
- **主控项目**：52项
- **一般项目**：38项
- **检验批数量**：30,000+

## 规范来源标识系统

为便于识别和操作，本项目建立了规范的来源标识系统：

| 标识 | 含义 |
|------|------|
| 【检评】 | JTG F80/1-2017《公路工程质量检验评定标准》条款要求 |
| 【施工】 | JTG/T 3660-2020《公路隧道施工技术规范》质量控制要求 |
| 【检评】【施工】 | 两规范均有要求，需同时满足 |

## 主控项目与一般项目

根据JTG F80/1-2017标准规定：

- **主控项目（带△）**：必须全部合格的关键质量指标
- **一般项目**：允许偏差，合格率≥80%

## 检验批编号规则

格式：`XX-YY-ZZ-NNN`

| 代码 | 含义 |
|------|------|
| XX | 隧道编号（ZK/YK/A/B/1#） |
| YY | 分部工程编号 |
| ZZ | 分项工程编号 |
| NNN | 检验批序号 |

示例：`ZK-03-01-001` 表示ZK左线洞身开挖第1个检验批
